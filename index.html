이 기기에만 저장 중

토큰을 넣으면 가격·‘다 먹었어요’·직접 추가가 GitHub의 inventory.json에 바로 저장돼요.

토큰 만드는 법 (1분)
  1. GitHub → Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token
  2. Repository access → Only select repositories → muji-fridge만 선택
  3. Permissions → Repository permissions → Contents: Read and write → Generate 후 토큰 복사

토큰은 이 폰 브라우저에만 저장되고 어디로도 전송되지 않아요. 남에게 보여주지 말고, 만료일은 1년 정도로 정해 두면 안전해요. 토큰을 지우면 ‘이 기기에만 저장’ 방식으로 돌아가요.
